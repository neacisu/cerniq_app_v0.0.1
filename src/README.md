# Bridge `src/` (monorepo root)

- **`App.tsx`** — re-export către `apps/web/src/App.tsx`. Nu folosi symlink: TypeScript rezolvă `./pages/*` relativ la directorul fișierului; un symlink spre `apps/web` rupe toate importurile relative.
- **`pages/**`** — re-export-uri opționale (ex. `etapa2/leads-import`, `etapa1/gold`) pentru analizori care deschid căi sub `src/pages`.
- **TypeScript / IDE** — nu există `src/tsconfig.json`: fișierele din `src/` intră în **același** proiect ca monorepo-ul (`tsconfig.json` la rădăcină). Un al doilea `tsconfig` în `src/` făcea ca editorul să folosească `compilerOptions`/`paths` diferite față de `packages/*` și `apps/*`, generând TS2307/7016/2344 pe re-exporturi.
- **`src/routes/`**, **`src/lib/`** — doar **shim-uri subțiri** (re-export către `apps/api/src/...`) pentru IDE / inventare care deschid aceste căi; runtime și contractul canonic rămân în **`apps/api`**. Fără logică duplicată aici.

Implementările canonice: **`apps/web/src/`** (UI), **`apps/api/src/`** (API), **`workers/ai/src/`** (worker AI / consensus). `src/consensus-vote-worker.ts` este doar **re-export** către `workers/ai/src/consensus-vote-worker.ts` (fără logică duplicată); nu copia conținutul workerului aici.

**Shim-uri API sub `src/`** (doar re-export, fără logică): `src/errors/handler.ts`, `src/metrics.ts`, `src/plugins/metrics.ts`, `src/plugins/audit-trail.ts`, `src/plugins/request-logging.ts`, `src/lib/monitoring-internal-fetch.ts`, `src/routes/{cognitive-brain,dashboard,import-logs-stream,outreach}.ts` — către `apps/api/src/...`.

**Shim-uri `@cerniq/observability` sub `src/`**: `src/init.ts`, `src/logger.ts`, `src/audit-writer.ts`, `src/job-logger.ts` — către `packages/observability/src/...` (aceeași logică ca importul din pachet; evită TS2344/2769/2307 când IDE-ul deschide căi `CerniqAPP/src/*.ts`).

Pentru **`tsconfig.json` (rădăcină)**: includem **`src/fastify-jwt-bootstrap.ts`**, **`src/fastify-rate-limit-bootstrap.ts`**, **`src/fastify-request-shim-augmentations.d.ts`**, **`src/web-css-shim.d.ts`** (JWT, `app.rateLimit`, `tenantId`, declarații `*.css`). În **`package.json` rădăcină** trebuie declarate (devDependencies) cel puțin: **`@opentelemetry/api`**, **`@opentelemetry/instrumentation`** (lanț de tipuri pentru **`@fastify/otel`**), **`@opentelemetry/auto-instrumentations-node`**, **`@opentelemetry/instrumentation-http`**, **`@fastify/otel`**, **`pino`**, **`drizzle-orm`**, **`fastify-plugin`**, **`@fastify/jwt`**, **`@fastify/rate-limit`**. Mapările **`paths`** pentru **`@opentelemetry/*`**, **`@fastify/otel`**, **`pino`** încep cu **`./node_modules/...`** (hoist la rădăcină), apoi fallback la **`packages/observability/node_modules/...`**. **`packages/observability/tsconfig.json`** rămâne pentru build-ul pachetului. Rulează **`pnpm install`** la rădăcina monorepo-ului.
