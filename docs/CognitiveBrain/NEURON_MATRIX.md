# NEURON_MATRIX

Îmi asum greșeala anterioară: **umplerea fișierului prin migrare automată (script) nu este „gândire individuală per neuron”**. Acest document este refăcut ca **matrice editorială**: coloana `scop_rational` trebuie să rezulte din **citirea contractului** la `contract_path` (secțiunea «Scop în context real» / «Scop in context real») și din **sinteză în propriile cuvinte** (2–4 propoziții), fără surse care nu apar în acel contract.

**Reguli:** nu inventați cozi, fișiere sau comportamente care nu sunt menționate în contract. Indexul mecanic (linie v2, registry, catalog) rămâne în [`NEURON_MATRIX.csv`](NEURON_MATRIX.csv), produs de `docs/CognitiveBrain/scripts/build_neuron_matrix.py` — **acel script nu scrie și nu trebuie să scrie** acest `.md`.

**Stare livrare:** mai jos sunt **toți cei 324 de neuroni** în același tabel. Rândurile **E1–E5** (inclusiv duplicatul `ai:intent:classify` la E2, intrările `churn:*` / `feedback:*` / `nurturing:*` unde apar în graf, dublurile `hitl:task:resolve` / `email:cold:add-to-campaign` / `wa:send:*` pe etape diferite, instanța E5 a `bronze:ingest:pdf-extractor` și perechea `audit:data:anonymize` / `compliance:data:anonymize` cu același runtime) au `scop_rational` redactat după citirea contractului la `contract_path` (2–4 propoziții, fără presupuneri dincolo de contract).
